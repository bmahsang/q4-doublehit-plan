체크포인트 — 리오더 판단 중심
발주 물량 50,000장은 전량 소진 필수. 체크포인트는 추가 리오더 여부와 채널 간 재배분 판단 기준입니다.
9월 4주
런칭 주간 반응 체크
스스+쿠팡 선오픈 후 첫 주 판매량. SS 시즌 업사이드가 FW로 이어지는지 확인
업사이드 확인 → 추가 리오더 검토 착수 (생산 리드타임 역산)
10월 2주
채널 선오픈 확정 + 추가 채널 논의
무신사/29cm 구좌 확정 여부. 미확정 시 해당 물량(5,000장) 재배분 채널 지정. 자사몰/오프라인 오픈 시점 확정
구좌 미확정 → 스스/쿠팡 물량 전환 or 신규 채널(에이블리 등) 대안 검토
10월 5주
1차 리오더 의사결정
전체 소진율 20% (10,000장) 이상 + 속도 유지 시 리오더 실행. 패턴/솔리드 중 어느 쪽이 빠른지 확인
리오더 실행 → 11월 피크 맞춰 입고 가능한 수량 산정 (리드타임 4~6주)
11월 2주
중간 점검 — 모자를 때 / 남을 때 판단
누적 소진율 40% (20,000장) 기준. 패턴/솔리드 각각 확인
모자랄 때 → 2차 리오더 긴급 검토. 피크 주간(11월 3주) 물량 확보
남을 때 → 채널 간 물량 재배분. 소진 느린 채널 → 빠른 채널로 이동. 할인은 전략팀 협의 필수
11월 4주
리오더 최종 컷오프
누적 65% (32,500장) 이상? 이후 리오더는 1월 입고 → 시즌 아웃이므로 의미 없음
남을 때 → 12월 프로모 강도 결정 (할인폭, 번들 구성). 리오더 중단
모자랄 때 → 남은 재고 최대한 고마진 채널(자사몰)에 집중
12월 4주
시즌 마감 점검
누적 85% (42,500장) 이상이면 정상. 미달 시 1월 소진 전략 가동
남을 때 → 1월 할인/번들/아울렛 처분 계획. 이월 여부 결정
